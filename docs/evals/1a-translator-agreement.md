# Phase 1a — ESPN vs nflverse translator agreement

Plan 10 A2a (plan 08 E8, §3.2 cross-check, property P15). Every fixture player-week that both sources
report is translated twice — `statLineFromEspn` on the recorded, anonymised ESPN box scores
(`fixtures/espn/recorded/`, read through the golden path guard) and `statLineFromPlayerWeek` /
`statLineFromTeamDefense` on the committed nflverse excerpt (`fixtures/golden/nflverse-crosscheck.json`,
whose source files are pinned by sha256) — and scored under each of the three recorded leagues'
own settings.

The table and lists below are generated by `tests/golden/translator-agreement.test.ts`, which fails
when this page differs from what the run computes. Regenerate with
`UPDATE_EVALS=1 scripts/dev/with-node.sh npx vitest run --project unit tests/golden/translator-agreement.test.ts`.

- **Hard (asserted in CI):** on the stats whose raw values agree, points agree within 0.005 per stat
  and 0.01 per player-week total under every league; no raw value differs by more than one yard or
  one event; the set of raw differences is pinned in the test, so a regenerated excerpt that changes
  it is reviewed, never widened blindly; D/ST points and yards allowed equal ESPN's raw stats 120 and
  127.
- **Reported (this page):** the list of raw differences greater than one yard or one event (plan 10
  A2a), and every smaller difference, which is the record of the two sources' conventions.
- **The one convention seen:** `two_pt_total` (ESPN stat 62). ESPN leaves 62 off some lines whose
  pass/rush/receiving two-point stats (19, 26, 44) record a conversion; nflverse's union is complete.
  None of the three recorded leagues scores stat 62 — each scores the per-type stats 19, 26 and 44
  (league-a with 26 at 0 points) — so on these leagues the gap never reaches a score; a league that
  scores 62 would see it. Fumble attribution, the expected offender, did not differ on this excerpt.
- Weeks 1–3 of one season and the fixture roster only: this is a record of what the excerpt shows,
  not a claim about every player-week.
