# fixtures/fx10h-usage — attribution, provenance and licences

Usage rows for the **fx-10h fixture league** (plan 10 B2: `espn_get_player_usage` returns trailing
summaries for ≥ 95 % of the fixture league's rostered players). The shared excerpts
(`../nflverse/`, `../nflverse/phase2/`, `../ffopportunity/`) are cut around the 24 fixture-roster
players; these supplements hold the rows of every other fx-10h rostered QB, RB, WR, TE and K
(all recorded scoring periods, 151 players, every one resolved espn_id → gsis_id
through the weekly rosters) that a live league's first `eff refresh all` would load. The dataset seed
(`tests/integration/helpers/seed.ts`) serves each shared excerpt **plus** its supplement at the
release URL, as one file in the shared excerpt's schema; nothing else reads these files, so every
other suite keeps reading the shared excerpts unchanged. A rostered D/ST has no player row in any of
these sources (D1: "no usage model for D/ST").

**Retrieved:** 2026-10-06, from the GitHub release assets
`https://github.com/nflverse/nflverse-data/releases/download/{tag}/{file}` and
`https://github.com/ffverse/ffopportunity/releases/download/latest-data/{file}`; generated by
`tests/sources/nflverse/helpers/make-fx10h-usage.ts` from local copies (no network at generation or
test time). Week ranges mirror the shared excerpts: weekly rosters weeks 1–4; player stats (REG),
snap counts and expected points weeks 1–3.
